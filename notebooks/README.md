# Notebooks - Training Models trên Kaggle

**Owner:** Quốc Anh (CNN) + Tấn Lộc (ResNet50) | **Deadline:** 11/12/2025

## Training trên Kaggle

1. Upload `CNN.ipynb` hoặc `ResNet.ipynb` lên [Kaggle](https://www.kaggle.com/code)
2. Add dataset: "chest xray pneumonia"
3. Enable GPU: Settings → GPU T4 x2
4. Run training (~2-3 giờ)
5. Download model `.h5` về thư mục `models/`

## Notebooks

- `CNN.ipynb` - Quốc Anh train CNN model
- `ResNet.ipynb` - Tấn Lộc fine-tune ResNet50
- `comparison/Model_Comparison.ipynb` - Tấn Lộc so sánh 2 models

## Expected Results

- CNN: ~88-92% accuracy
- ResNet50: ~92-96% accuracy
